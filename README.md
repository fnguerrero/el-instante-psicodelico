# Duermevela

> **Estado: Activo** — en desarrollo.

Continúa la historia de Bel, la de [Kermés](https://github.com/fnguerrero/kermes): otra noche,
entre arcanos y figuras.

HTML y JavaScript puro, sin dependencias ni build: se abre `index.html` y anda.

## Cómo está armado

| Carpeta | Qué hay |
|---|---|
| `js` | El juego: guion, escenas, dibujo, figuras y arcanos |
| `css` | Estilos |
| `test` | Pruebas |
| `tools` | Servidor local y utilidades de build |
